# CodePath 🎓

An installable app with the **whole programming roadmap in one place** — 8 sections, **92 topics**,
and every topic opens the best YouTube videos for it in a new tab.

Tapping anywhere on a topic card (or its **▶ Watch on YouTube** button) opens YouTube for that
topic. Each card also lists the top channels for the topic (CodeWithHarry, Apna College, Striver,
freeCodeCamp, Telusko, Amigoscode, Abdul Bari, Gate Smashers, TechWorld with Nana, …) — tap a
channel chip to search *that* channel for the topic.

## Features

- **Tap a topic → YouTube opens** with a topic-specific search (new tab, mobile friendly).
- **Section buttons** in one scrollable row, each with its own `done/total` counter.
- **Live search** across titles, descriptions, channels and project features (`/` focuses it, `Esc` clears).
- **Progress tracking**: mark topics done, per-section bars, an overall ring, saved in `localStorage`.
- **Bulk actions per section**: every section header has **✓ Mark all done**, which flips to **↺ Clear section** once that section is finished. It respects the active filter, so with a search active it only marks the topics you can see.
- **Star your favourite topics**: tap the **☆** on any card to save it and read it back later from the **⭐ Favourites** tab (with a live count). Stars are independent of progress and are kept when you reset progress.
- **▶ Continue button** always takes you to the next unfinished topic.
- **🔄 Reload** re-renders the whole list from the data file and clears all filters.
- **♻️ Refresh page** does a hard page reload.
- **⬇️ Install app** installs it to your home screen / desktop with its own app icon and works offline.
- **💾 Export / 📂 Import your progress** as a JSON backup file (see below).
- **🌗 Light/dark theme**, "Hide completed" filter, deep links (`#dsa`, `#favourites`, `#projects`), toasts, keyboard support.
- Two browser tabs stay in sync automatically (`storage` events).
- No build step, no framework, no external requests — three plain files and vanilla JS.

## Run it

```bash
npm start            # http://localhost:4173
```

`index.html` also works if you just double-click it — service worker and install are simply skipped
on `file://`. Use `npm start` (or any static server) to get the installable PWA.

### Install as an app

- **Android / desktop Chrome/Edge:** open the site → **⬇️ Install app** button (or browser menu → *Install app*).
- **iPhone/iPad Safari:** Share → *Add to Home Screen*. The icon above is what shows up.

## Verify

```bash
npm run check    # syntax check every script + validate all asset references
npm test         # 13 core unit tests + curriculum data validation (no dependencies)
npm run test:ui  # 18 jsdom integration tests that drive the real UI (needs devDependencies)
npm run test:all # everything
```

The data validation fails the build if any syllabus item is missing, an id collides or a YouTube
URL is malformed. The UI tests boot the real `index.html` and check rendering, tab switching,
search, marking topics done, reload, reset and deep links.

## Releases (the APK on GitHub Releases)

A GitHub Actions workflow (`.github/workflows/release.yml`) builds the signed APK and attaches it
to a GitHub Release automatically. Just push a version tag:

```bash
git tag v1.0.1
git push origin v1.0.1
```

Within a few minutes the **Releases** page of the repo shows *CodePath v1.0.1* with
`codepath-v1.0.1.apk` as a download asset. You can also start it by hand: **Actions →
Build & attach APK to release → Run workflow**, type the tag (e.g. `v1.0.1`) and run it.

The release workflow runs `npm run test:all` first and refuses to publish if anything fails.
Tags containing a `-` (e.g. `v1.0.1-beta`) are marked as pre-releases.

## Add your own topic

Edit `js/data.js` and add an object to a section's `topics` array:

```js
{
  t: 'Kafka Basics',                       // title
  d: 'Producers, consumers, topics, partitions.',  // one-line description
  q: 'kafka tutorial for beginners',       // base YouTube search
  ch: ['Amigoscode', 'Fireship'],          // channels, best first
  f: ['optional', 'list of features']      // optional bullet list
}
```

Then run `npm test` — it re-checks link shape, duplicates and coverage.

> Links point at YouTube **search** results (`topic + top channel`) rather than hard-coded video
> ids, so they never go stale when a creator re-uploads, renames or deletes a video.

## Backup: export & restore

The two buttons in the footer move your progress between devices or keep a safety copy:

- **💾 Export backup** writes `codepath-backup-YYYY-MM-DD.json`:

  ```json
  {
    "app": "codepath",
    "kind": "progress-backup",
    "version": "1.0.0",
    "exportedAt": "2026-09-16T10:04:11.482Z",
    "counts": { "completed": 12, "favourites": 3 },
    "done": { "dsa::Stack": true },
    "bookmarks": { "tools::Git": true }
  }
  ```

  (If a browser blocks Blob downloads the app falls back to a `data:` URI automatically.)

- **📂 Import backup** reads that file — or a bare `{ "dsa::Stack": true }` map — and **merges** it into what you already have, so restoring an old file can never wipe newer progress. Imported entries are validated against the curriculum: unknown ids, junk values and duplicates are skipped and reported in the toast ("2 unknown entries skipped").
- A corrupt or unrelated file is rejected with a clear message and changes nothing.
- The same file can be imported repeatedly. For a **clean restore**, hit *Reset progress* first, then import.

### Where your data lives

| `localStorage` key | What it stores |
|---|---|
| `codepath:done` | completed topics (`sectionId::Topic title`) |
| `codepath:bookmarks` | starred favourites |
| `codepath:theme` | `dark` or `light` |

Nothing is ever uploaded — export/import works entirely with local files.

Both maps are independent: **Reset progress** only clears `codepath:done` and keeps your favourites.
Corrupt or hand-edited values are ignored instead of breaking the app (covered by a test).
